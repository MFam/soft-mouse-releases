Soft Mouse 0.1.8

  • 마우스별 설정: 설정이 프로필(기본 프로필 + 추가 가능) 단위로 저장되고, 새 "마우스별 설정" 페이지에서 마우스마다 프로필을 배정할 수 있습니다. 블루투스·유선 마우스를 자동으로 인식합니다.
  • 일반 페이지 상단에서 편집 중인 프로필을 고르고 추가·복제·이름 변경·다른 프로필 가져오기를 할 수 있습니다. 메뉴 막대에는 사용 중인 마우스와 프로필이 표시됩니다.
  • 앱별 설정에 "이 앱에서 Soft Mouse 사용 안 함" 옵션을 추가했습니다.
  • 기존 설정은 기본 프로필로 자동 이관됩니다.
