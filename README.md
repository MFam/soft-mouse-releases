# Soft Mouse 릴리스

macOS용 Soft Mouse의 배포 파일과 자동 업데이트 피드입니다.

- **다운로드**: 이 저장소의 최신 `SoftMouse-<버전>.dmg`
- **자동 업데이트**: 앱이 `appcast.xml`을 하루 한 번 확인하고 새 버전이 있으면 알려줍니다. 메뉴 막대 › 업데이트 확인, 또는 설정 › 정보 › 지금 확인으로 즉시 확인할 수 있습니다.
- 모든 파일은 Developer ID로 서명·공증되었고, 업데이트 패키지는 EdDSA로 추가 서명되어 앱이 검증합니다.

소스 코드는 별도 비공개 저장소에서 관리합니다.
